# BoxBot

This needs to be a bare-bone in-browser app for helping art handlers design custom boxes for medium or large-scale artworks. The art handlers will have 4x8 sheets of cardboard, the sizes of the artworks, the padding space required along the edges as well as the padding in front and in back of the artwork respectively. They need to know what sizes they will need to cut out of the 4x8 cardboard sheets and where they will have to create creases. This tool should help them make the most efficient use of cardboard sheets possible but it is fine for them to have scaps left over. Joining multple pieces of cardboard together should be avoided when possible. The tool should be able create clamshell type boxes as well as botom / lid boxes. The output should be simple black and white printable diagrams showing the exact measurements for cuts and folds.
